# 👋 ¡Hola! Bienvenido a mi GitHub

🎓 Soy estudiante de Informática en la UMSA, con interés en la **ciberseguridad ofensiva, el pentesting y el desarrollo de software**.

Actualmente estoy siguiendo una ruta de formación práctica en pentesting, utilizando Kali Linux, laboratorios autorizados y proyectos técnicos.

## 🛠️ Tecnologías y conocimientos

- **Lenguajes:** Java, conocimientos básicos de Python y C#.
- **Sistemas:** Linux, terminal y administración básica.
- **Seguridad:** permisos de Linux, procesos, búsquedas de archivos y fundamentos de SSH.
- **Herramientas de desarrollo:** NetBeans, PyCharm, IntelliJ IDEA y GitHub.

## 🚀 Formación en ciberseguridad

Actualmente desarrollo mis habilidades en:

- Linux y scripting Bash.
